# InternCircle Project 01 — Profile Card

A single-screen Flutter profile card for Mugunthan M. It uses a dark theme with
green accents and adapts to narrow screens and wider layouts.

## Requirements

- Flutter SDK (with Dart)
- An emulator, connected device, or Flutter-supported desktop/browser target

## Run

```shell
flutter pub get
flutter run
```

To run the widget test:

```shell
flutter test
```

## Personalize contact details

Open `lib/main.dart` and replace `[Insert your email]` and
`[Insert your phone number]` with your preferred contact information.

This project uses Flutter's built-in Material widgets and icons only. It has no
external package or API dependencies.
